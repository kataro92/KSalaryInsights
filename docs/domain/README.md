# Kho tri thức nghiệp vụ

Mỗi file theo format: khái niệm → công thức → tham số hiện hành (nguồn + ngày hiệu lực) → ví dụ tính tay → edge case.

Xem constitution nguyên tắc I-IV.

**Xác minh nguồn**: mọi tham số có tầng xác minh (Tầng 1 = văn bản gốc, Tầng 2 = thứ cấp) theo dõi tại [legal-sources.md](./legal-sources.md). Chỉ Tầng 1 đủ điều kiện ship (Constitution I v1.1.0). Văn bản không tự tìm được → yêu cầu product owner cung cấp.
