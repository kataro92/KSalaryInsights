## 2. ❗ Còn cần cung cấp

**KHÔNG CÒN** — đã nhận đủ đợt 1 (2026-07-31) + đợt 2 (2026-07-31) + đợt 3 (2026-08-01, Luật Dân số 113/2025). Toàn bộ tham số trong domain docs / specs 001–008 đạt **Tầng 1**.

Danh sách sẽ mở lại khi: (1) có nghị định hướng dẫn mức trần giảm trừ y tế/giáo dục (Đ.11 k2 Luật 109/2025); (2) luật/nghị định mới ban hành ảnh hưởng tham số (theo dõi qua `legal-changelog.md`).

**Định dạng nhận**: PDF/bản chụp công báo hoặc link vanban.chinhphu.vn / congbao.chinhphu.vn. Đặt vào `docs/legal-originals/`, tên `<số-hiệu>.pdf`.

## 3. Quy trình khi nhận văn bản gốc

1. Lưu file vào `docs/legal-originals/`, ghi ngày nhận vào bảng mục 1, nâng ⚠/❌ → ✅.
2. Đối chiếu **từng tham số** trong domain docs với điều khoản gốc; ghi số điều khoản chính xác.
3. Nếu lệch với nguồn thứ cấp → sửa domain + test case + legal-changelog, chạy lại analyze.
4. Spec chỉ được `/speckit-plan` → implement → ship khi mọi tham số nó dùng đạt ✅.
