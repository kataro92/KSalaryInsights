# UI icons (PNG)

Monochrome PNG icons for in-app chrome (tabs, chevrons, hub cards, info tips, list bullets).

- Regenerate: `node scripts/generate-ui-icons.mjs`
- Use via `AppIcon` (`src/components/common/AppIcon.tsx`) with `tintColor`
- Do **not** use emoji or Lucide SVG in user-facing UI content
